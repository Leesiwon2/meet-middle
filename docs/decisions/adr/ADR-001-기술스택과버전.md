# ADR-001: 기술 스택과 기준 버전

> 상태: **Accepted** · 작성일: 2026-11-11 · 결정일: 2026-11-11
> 관련: [TECH-STACK.md](../../dev/TECH-STACK.md) (버전 정본), [ADR-002](ADR-002-대중교통API선정.md)
> 범위: 백엔드·프론트엔드·로컬 인프라. 배포 환경은 범위 밖(후속 ADR).

## 1. 맥락

링크 공유형 웹 서비스(중간지점 추천)를 1인 개발로 시작한다. 개발자는 Java/Spring(Java 21 · Spring Boot 3.5) 과 React(React 19 · Vite) 경험이 있다.

## 2. 기준

1. 익숙함: 이미 아는 언어·프레임워크로 학습 비용 최소화
2. 지원 기간: 2026-11 시점에 신규 프로젝트로 시작해 최소 2년 지원되는 버전
3. 생태계 호환: 린트·코드 생성·테스트 도구가 그 버전을 공식 지원
4. 로컬 공존: 기본 포트를 쓰는 다른 로컬 서비스와 충돌하지 않음
5. AI 코딩 효율: 자료가 많고 규칙이 명확한 도구
